# Game Module

`dnd1` — игровой Django-модуль проекта `AI Arrow Hack`.

Он отвечает за:

- создание кампаний;
- генерацию карты и игровых сущностей;
- хранение истории партии;
- запуск игровой сессии, которая используется для оценки soft skills кандидата.

## Запуск

```bash
pip install -r ../requirements/game.txt
python3 manage.py runserver 0.0.0.0:7000
```

## Конфигурация

- AI-ключи берутся из корневого `.env`;
- при необходимости можно использовать локальный `DnD_AI/API.py`, но этот файл не должен попадать в git;
- generated-иллюстрации складываются в `media/illustrations/` и не коммитятся.
